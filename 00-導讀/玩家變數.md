# 玩家變數

現行 Variable 行為；完整方案背景見[方案草稿](../90-參考附件/方案草稿/玩家變數與資源消耗規範.md)。

- 定義：Luban `Variable`，Runtime 使用 `int64`、default、上下限與 `SyncClient`。
- 保存：只保存非 default 的 sparse variable；玩家恢復時一併載入。
- 同步：登入回傳 Client 可見變數；登入後只回傳變更值。
- 權威：Server 決定數值與扣除結果，Client 不得自行修改。
- 實作：`cmd/world/internal/variable`；配置載入見 `config.go`，快照見 `Snapshot`。

變數 migration 使用[配置操作入口](../30-部署與開發/配置操作入口.md)。
