# 道具取得與背包

現行道具取得與保存邊界；其他 Item Action 規劃見[方案草稿](../90-參考附件/方案草稿/道具取得與使用系統規範.md)。

- Inventory 取得：道具加入玩家背包並保存堆疊數量。
- Immediate 取得：不進背包，直接產生 Item Action 計畫。
- 目前支援：`Item.Type = 1`，以 `AdjustVariable` 增減 Variable。
- Server 驗證設定、數量與玩家權限；Client 不決定實際結果。
- 實作：`internal/game/item`、`internal/game/itemconfig`。

`tools/itemsim` 可模擬取得或使用結果。
