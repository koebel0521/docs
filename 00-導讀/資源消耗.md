# 資源消耗

現行資源扣除行為；完整方案背景見[方案草稿](../90-參考附件/方案草稿/玩家變數與資源消耗規範.md)。

- 金幣（`Gold`）：背包道具 `SharedItemID_Gold`，不是 Variable；商店付款走道具扣除。程式裡沒有 Currency 型別或 Currency Service。
- `Variable`：玩家變數型資源，成本以 `Cost.IsVariable` 標記；不要再用「Currency」稱呼變數。把金幣成本寫成 `IsVariable: true` 會去讀同 ID 的玩家變數，金幣足夠也會判定不足。
- `Inventory`：以玩家背包道具作為可消耗資源。
- `Cost`：統一檢查與扣除 variable、item，必要時附帶 operation 與 reason。
- 交易：多資源扣除在同一筆 MySQL transaction 完成，任一項失敗即 rollback。
- 事件：帶 operation ID 的消耗寫入 Record outbox，失敗會 retry 或進 dead-letter。outbox 兼任冪等鍵與流向帳，只送 Record 分析；任務進度不經它投遞，見[任務系統](../10-核心流程/任務系統.md)。

主要實作位於 `internal/game/board/costs.go`（`DeductCosts`、`DeductItem`）與 `cmd/world/internal/store/gamestore`。
