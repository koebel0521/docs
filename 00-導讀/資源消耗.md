# 資源消耗

現行資源扣除行為；完整方案背景見[方案草稿](../90-參考附件/方案草稿/玩家變數與資源消耗規範.md)。

- `Currency`：以 Variable 保存的貨幣，由 Currency Service 提供業務語意。
- `Inventory`：以玩家背包道具作為可消耗資源。
- `Cost`：統一檢查與扣除 currency、item，必要時附帶 operation 與 reason。
- 交易：多資源扣除在同一筆 MySQL transaction 完成，任一項失敗即 rollback。
- 事件：帶 operation ID 的消耗寫入 Record outbox，失敗會 retry 或進 dead-letter。

主要實作位於 `cmd/world/internal/cost`、`currency` 與 `store/gamestore`。
