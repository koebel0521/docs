# 日誌輸出格式

所有服務透過 `pkg/logger` 輸出日誌，預設為人類可讀的 `text` 格式。

本專案的 Go module path 是 `local/server`，因此服務內部套件使用 `local/server/...` 匯入；這是本機 module 名稱，不代表需要連線到外部網站。

啟動服務時可切換為 JSON：

```powershell
go run ./cmd/gate --config config/dev/gate.yaml --log-format=json
```

`--log-format` 適用於所有 `cmd/*` 服務，可使用 `text` 或 `json`。JSON 格式適合容器平台、集中式日誌收集器與機器解析；開發者本機閱讀則保留預設的 `text`。

日誌層級可搭配 `--log-level=debug|info|warn|error` 設定。
