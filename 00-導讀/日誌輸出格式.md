# 日誌輸出格式

所有服務透過 `pkg/logger`（zerolog）輸出日誌，預設為 `json` 格式，方便容器平台、集中式日誌收集器與機器解析。

本專案的 Go module path 是 `local/server`，因此服務內部套件使用 `local/server/...` 匯入；這是本機 module 名稱，不代表需要連線到外部網站。

本機閱讀可切換為人類可讀的 `text`：

```powershell
go run ./cmd/gate --config config/dev/gate.yaml --log-format=text
```

`--log-format` 適用於所有 `cmd/*` 服務，可使用 `text` 或 `json`。讀取設定之前（解析旗標失敗等極早期錯誤）的少數日誌一律是 `text`。

日誌層級可搭配 `--log-level=debug|info|warn|error` 設定，預設 `info`。
