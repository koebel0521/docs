# 日誌輸出格式

所有服務透過 `pkg/logger`（zerolog）輸出日誌，預設為 `json` 格式，方便容器平台、集中式日誌收集器與機器解析。

本專案的 Go module path 是 `local/server`，因此服務內部套件使用 `local/server/...` 匯入；這是本機 module 名稱，不代表需要連線到外部網站。

本機閱讀可切換為人類可讀的 `text`：

```powershell
go run ./cmd/gate --config config/dev/gate.yaml --log-format=text
```

`--log-format` 適用於所有 `cmd/*` 服務，可使用 `text` 或 `json`。讀取設定之前的少數日誌一律是 `text`。旗標解析失敗（含 `-log-level`／`-log-format` 值不合法）不是日誌：以純文字錯誤加用法寫 stderr（沒有時間戳與層級欄位），結束碼 2。`text` 格式只在 stderr 是終端機時帶 ANSI 色碼（導向檔案或管線時自動關閉）；`NO_COLOR` 環境變數非空時一律關閉。

日誌層級可搭配 `--log-level=trace|debug|info|warn|error` 設定（`warning` 視同 `warn`），預設 `info`；未給旗標時 `--log-level` 讀環境變數 `LOG_LEVEL`、`--log-format` 讀 `LOG_FORMAT`，值寫錯一律以結束碼 2 拒絕啟動。其餘設定覆寫規則見[設定注入與熱更新](./設定注入與熱更新.md)。

## 非同步日誌（`LOG_ASYNC_BUFFER`）

環境變數 `LOG_ASYNC_BUFFER`（筆數，預設 0＝關閉，行為與以前相同）。開啟後日誌先進 zerolog diode 環形緩衝、由單一 goroutine 寫 stderr，Gate／World 事件迴圈不再為每行日誌付一次 write syscall（本機 benchmark：同步約 2.6µs/op → 非同步約 0.19µs/op，3 allocs）。和 `LOG_SAMPLE_RATE` 一樣只讀環境變數（logger 在讀設定檔前就要設定）。

- 取捨：緩衝滿了會丟**最舊**的日誌，計入 `logger_async_dropped_total`，並在 stderr 寫一行 Warn `async log buffer overflow, entries dropped`（欄位 `dropped`、`droppedTotal`）。
- 行程崩潰（panic、SIGKILL）時，緩衝內最後幾筆可能遺失；正常結束由 `startup.Main` 的 `logger.Close()` 排空。玩家連線的 connect／disconnect 已改記 Debug（S2S 連線維持 Info）。
- 標準庫 `log` 的橋接（OTel 匯出錯誤、`net/http` 內部錯誤、diode 槽位碰撞回報）在非同步模式下**同步寫 stderr、不經 diode**：diode 碰撞時以標準庫 `log` 回報，若橋接再寫回同一個 diode，第二次碰撞會在 `log.Logger` 的鎖上自鎖，讓所有寫日誌的 goroutine（含事件迴圈）永久阻塞。
- 值不是整數（例如 `4k`、`1e4`）時啟動記一行 Warn `LOG_ASYNC_BUFFER invalid, async logging disabled`（欄位 `value`、`err`）並維持同步日誌，不再靜默關閉。
- 建議壓測時先在單一服務試開（例如 8192）並觀察 `logger_async_dropped_total`；是否正式環境預設開啟尚未決定。
