# 故障單模板

> 用途：每次事故都用同一份格式記錄，方便復盤、交接與後續修正。

## 基本資訊

| 欄位 | 內容 |
|------|------|
| 故障編號 | `INC-YYYYMMDD-001` |
| 事件名稱 |  |
| 發生時間 |  |
| 發現時間 |  |
| 結束時間 |  |
| 影響範圍 |  |
| 影響等級 | `page / warning / ignore` |
| 負責人 |  |
| 相關服務 | `Central / Gate / World / Lobby / User` |

## 現象

- 看到什麼
- 哪個指標先壞
- 哪個路由或流程先出問題
- 有沒有告警、重試、回退

## 影響

- 受影響玩家數
- 受影響功能
- 影響持續多久
- 有沒有資料遺失或重複

## 時間線

1. `HH:MM` - 事件開始
2. `HH:MM` - 第一個告警
3. `HH:MM` - 先做了什麼
4. `HH:MM` - 哪一步回復
5. `HH:MM` - 事件結束

## 處置

- 當下做了什麼
- 關了哪些開關
- 切了哪些流量
- 重啟了哪些服務
- 跑了哪些修復工具

## 回滾

- 是否回滾
- 回滾到哪一版
- 回滾是否成功
- 還有沒有殘留風險

## 根因

- 直接原因
- 深層原因
- 為什麼沒在更早階段被抓到

## 後續動作

- 要補的程式修正
- 要補的監控
- 要補的測試
- 要補的文件

## 附件

- log
- dashboard 截圖
- metrics 截圖
- 相關 commit
- 事故封存檔
