# 觀測總索引

這頁只管找路。先看這頁，再進各 runbook。

## 一句話順序

1. [本機監控](./本機監控.md)
2. `tools/dephealth`
3. `tools/opsdiag`
4. [指標面板](./指標面板.md)
5. [SLO值班流程](./SLO值班流程.md)
6. [狀態對帳流程](./狀態對帳流程.md)

若症狀是 `mismatch` / `error`，直接跳 `狀態對帳流程`，不要先往 `資源預算` 走。

## 症狀對路

| 症狀 | 先看 | 下一步 |
|------|------|--------|
| `ready` 壞 | `本機監控` -> `dephealth` | 先判服務有冇起來，再看 `opsdiag` |
| `status=degraded` | `dephealth` -> `資源預算` | 先修 backlog / queue，再看 handler log |
| `SLO` 掉 | `指標面板` -> `SLO值班流程` | 先看 `SLO Summary`，再鑽對應類別 |
| `mismatch` / `error` | `狀態對帳流程` | 先看 `result`，再追索引 / 依賴 / timeout |
| `repair` | `狀態對帳流程` | 先當已收斂一部分漂移，再追根因 |
| 不知道要看哪 | `問題排查筆記` | 先用排查工具箱收斂症狀 |

## 固定判讀

狀態詞定義（`ready` / `degraded` / `mismatch` / `error` / `repair`）統一見 [[觀測詞彙表]]，這裡不再重複。
