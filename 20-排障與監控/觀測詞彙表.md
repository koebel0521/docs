# 觀測詞彙表

這頁只管判讀詞。工具、面板、runbook 盡量都用同一套語意。

## 狀態詞

| 詞 | 意思 | 值班動作 |
|------|------|----------|
| `ready=ok` | 服務可用 | 繼續看下一層 |
| `ready=degraded` | 服務還在，但已碰到警戒線 | 先修 backlog / queue，再看 handler |
| `ready=down` | 服務真沒起 | 先看進程、依賴、啟動失敗 |
| `status=degraded` | 依賴健康已碰到 warn threshold | 不等於 down，先修資源壓力 |
| `mismatch` | 狀態不一致 | 先看索引 / route / cache |
| `error` | audit 或依賴失敗 | 先看 Redis / MySQL / timeout |
| `repair` | 已自動修回一部分漂移 | 續追根因，不要當完成 |

## 壓力詞

| 詞 | 意思 | 值班動作 |
|------|------|----------|
| `backlog` | 佇列或 pending 工作在堆 | 先看 handler 是否慢、consumer 是否慢讀 |
| `overflow` | 佇列已滿或丟工作 | 先看背壓、slow consumer、consumer 容量 |
| `queue high` | queue 深度碰線 | 先看 budget，再看 downstream |
| `downstream slow` | 下游消化慢 | 先看 timeout、retry、DB / Redis / remote service |

## 使用原則

1. `degraded` 不等於 `down`
2. `mismatch` 不等於 `error`
3. `repair` 不等於 done
4. 先看詞，再看圖，最後才看 log
