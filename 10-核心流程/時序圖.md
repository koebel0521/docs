# 時序圖

## 登入流程

```mermaid
sequenceDiagram
    participant U as User
    participant G as Gate
    participant C as Central
    participant W as World
    participant DB as MySQL
    participant R as Redis

    U->>G: LoginRequest(account, password)
    Note over G: 產生 request_id + trace_id
    Note over G: Session → pending_login

    G->>C: LoginGateToCentral(account, password, request_id, trace_id)
    Note over G,C: 同時攜帶 protocol_version

    Note over C: 檢查帳號鎖定（5次/10秒）
    Note over C: 檢查 request journal（去重）

    alt 帳號已鎖定
        C-->>G: LoginCentralToGate(ReturnAccountLocked)
        G-->>U: LoginResponse(fail)
    else 重複請求（replay cache hit）
        C-->>G: LoginCentralToGate(cached result)
        G-->>U: LoginResponse(cached result)
    else 無可用 World 或 DB/依賴失敗
        C-->>G: LoginCentralToGate(AuthServiceUnavailable / AuthSaveFail)
        Note over G: 清理 pending_login
        G-->>U: LoginResponse(fail)
    else 正常登入
        C->>DB: 查詢/建立帳號
        C->>C: 分配 World（world_id）
        C->>W: LoginCentralToWorld(account, player_data, request_id, trace_id)
        Note over C: 快取結果到 request journal（TTL 2分鐘）

        W->>R: 儲存玩家狀態
        Note over W: 加入在線玩家列表
        W-->>G: LoginWorldToGate(success, player_data, request_id, trace_id)

        Note over G: Session → logged_in
        G-->>U: LoginResponse(success, player_data)
    end
```

## Central 中途失聯後玩家重試

```mermaid
sequenceDiagram
    participant U as User
    participant G as Gate
    participant C as Central

    U->>G: LoginRequest(account)
    G->>C: LoginGateToCentral(request_id=A, trace_id=T1)
    Note over C: 處理中途斷線或重啟
    Note over G: session 保持 pending_login 直到 TTL 或錯誤返回

    alt Gate 偵測服務不可用
        G-->>U: LoginResponse(AuthServiceUnavailable)
        Note over G: 清理 pending_login
    else Gate 等待超時
        Note over G: 45 秒後 sweeper 清理 pending_login
    end

    U->>G: 再次登入
    G->>C: LoginGateToCentral(request_id=B, trace_id=T2)
    Note over G: 新鏈路使用新的 request_id / trace_id
    C-->>G: LoginCentralToGate(success)
    G-->>U: LoginResponse(success)
```

## 重複登入踢舊 Session

```mermaid
sequenceDiagram
    participant U1 as "User(舊連線)"
    participant U2 as "User(新連線)"
    participant G as Gate
    participant C as Central
    participant W as World

    U1->>G: 已登入並保持 logged_in
    U2->>G: LoginRequest(同帳號)
    G->>C: LoginGateToCentral
    C->>W: LoginCentralToWorld
    W-->>G: LoginWorldToGate(success)
    Note over G: 建立新 session，清理舊 session
    G-->>U1: AuthReLogin / forced logout
    G-->>U2: LoginResponse(success)
```

## 登出流程

```mermaid
sequenceDiagram
    participant U as User
    participant G as Gate
    participant C as Central
    participant W as World
    participant R as Redis

    U->>G: LogoutRequest()
    Note over G: Session → pending_logout
    Note over G: 產生 request_id + trace_id

    G->>W: LogoutGateToWorld(account, request_id, trace_id)
    W->>R: 清除玩家狀態
    Note over W: 移除在線玩家
    W-->>G: LogoutWorldToGate(success, request_id, trace_id)

    G->>C: LogoutGateToCentral(account, trace_id)
    Note over C: 清除路由資訊

    Note over G: Session → disconnected
    G-->>U: LogoutResponse(success)
```

## World 重啟恢復流程

```mermaid
sequenceDiagram
    participant G as Gate
    participant W as World
    participant C as Central
    participant R as Redis

    Note over W: World 重啟

    W->>R: 載入所有玩家狀態
    Note over W: 啟動 30 秒寬限期

    G->>W: TCP 重新連線
    W-->>G: ConnectInfo

    Note over W: 寬限期結束

    loop 每個恢復的玩家
        W->>G: ValidateGateToWorld(account)
        alt Gate 確認玩家仍在線
            G-->>W: ValidateResponse(valid)
            Note over W: 保留玩家
        else Gate 回報玩家已離線
            G-->>W: ValidateResponse(invalid)
            W->>R: 清除玩家狀態
            W->>C: 通知清除路由
        end
    end
```

## Gate 與 World 斷線處理

```mermaid
sequenceDiagram
    participant G as Gate
    participant W as World
    participant C as Central

    Note over G,W: TCP 連線中斷

    alt 短期斷線（< 30 秒）
        Note over W: 標記 Gate 為 unavailable
        Note over W: 保留所有玩家狀態
        G->>W: TCP 重新連線
        Note over W: 清除 unavailable 標記
        Note over W: 恢復正常運作
    else 長期斷線（> 30 秒）
        Note over W: 清理該 Gate 的所有玩家
        W->>C: 通知清除路由資訊
        Note over G: 清理所有 Session
        G->>G: 通知所有玩家斷線
    end
```

## Session 狀態機

```mermaid
stateDiagram-v2
    [*] --> disconnected
    disconnected --> pending_login: 收到登入請求
    pending_login --> logged_in: World 回覆成功
    pending_login --> disconnected: 超時(45s) / 失敗
    logged_in --> pending_logout: 收到登出請求
    logged_in --> disconnected: 連線中斷
    pending_logout --> disconnected: 登出完成 / 超時(30s)
```

## 請求去重機制

```mermaid
sequenceDiagram
    participant G as Gate
    participant C as Central

    G->>C: LoginGateToCentral(request_id=0x1001)
    Note over C: request journal 查無記錄
    Note over C: 處理請求...
    Note over C: 快取結果(TTL=2min)
    C-->>G: LoginCentralToGate(success)

    Note over G: 因網路問題重送

    G->>C: LoginGateToCentral(request_id=0x1001)
    Note over C: request journal 命中！
    Note over C: 直接返回快取結果
    C-->>G: LoginCentralToGate(success, from cache)
```
