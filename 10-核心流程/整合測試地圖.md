# 整合測試地圖

所有整合測試位於 `integration/`，依功能分類：

## 登入流程（Login）

| 測試 | 場景 |
|------|------|
| `TestGateUser_Login*` | 標準登入、pending_login、TTL expiry |
| `TestGateWorldCrossService_Login*` | Central→World 跨服務登入 |
| `TestGateUser_LoginRateLimited*` | Rate limit 保護 |
| `TestGateUser_DuplicateLogin*` | 重複登入 / 踢舊 session |
| `TestGateUser_CentralDirectLogin_ErrorCodes` | Central 直接通知登入失敗的錯誤碼轉傳 |

## 聊天功能（Chat）

| 測試 | 場景 |
|------|------|
| `TestGateUser_Chat*` | ChatSend / Join / Leave / Sync / Deliver |
| `TestChat_*` | 真實 Chat process 測試 |
| `TestGateUser_ChatSendDuring*` | 斷線期間聊天行為 |

## 多人壓力

| 測試 | 場景 |
|------|------|
| `TestGateUser_MultiUser*_Stress` | 多人並發壓力 |

> 頻道（`TestGateUser_Channel*`、`TestGateUser_LargeChannelPayload`）測試已隨頻道功能移除。

## 斷線重連（Reconnect）

| 測試 | 場景 |
|------|------|
| `*Reconnect*` | Gate / World / Central 斷線重連 |
| `*Restart*` | 服務重啟後恢復 |
| `TestGateUser_Disconnect*` | 使用者斷線 cleanup |
| `TestGate_GracefulShutdown` | SIGINT 優雅關閉 |
| `TestGateUser_ReconnectBeforeCleanupComplete` | 快速重連 |

## Lobby 管理

| 測試 | 場景 |
|------|------|
| `TestLobbyAdmin_KickEndToEnd` | 踢人全鏈路 |
| `TestLobbyAdmin_BanUnbanViaHTTP` | 封禁 / 解封 |
| `TestLobbyAdmin_GrantItemEndToEnd` | 發道具全鏈路 |
| `TestLobbyAdmin_InputValidation` | 輸入驗證（9 種邊界） |

## 協定與邊界

| 測試 | 場景 |
|------|------|
| `TestGateUser_InvalidMsgID_ClosesConnection` | 無效 msgID 不 panic、連線被關閉 |
| `TestGateUser_UndersizedPacket*` | undersized frame 斷線 |
| `TestGateVersionHandshake_*` | Gate 版本握手：版本相符放行、協定或契約不同回強制更新並斷線、沒先 Hello 直接斷線 |
| `TestGateUser_LongAccount*` | 512 bytes 帳號 |
| `TestGateUser_MalformedPacket*`、`TestGateUser_OversizedPacket*` | 異常、超大封包斷線 |

## 跨服務協作

| 測試 | 場景 |
|------|------|
| `TestGateWorldCrossService_*` | World 斷線 grace / pending_logout 共存 |
| `TestCentral*` | Central 重啟 / 直接登入回應 |
| `TestGateUser_PendingLoginTTLExpired`、`TestGateUser_PendingLogoutExpiry*` | pending_login／pending_logout 到期清理 |
| `TestGateUser_AuditSnapshot*` | Audit snapshot |
| `TestGateUser_ClientTimeSync` | Client 以 TimeSyncRequest 校時（Gate 不轉發 Central 的 TimeSync） |

## 冒煙與端到端流程

| 測試 | 場景 |
|------|------|
| `TestSmoke_ClusterReadyAndLogin` | 真實 Central／World／Gate 的 `/health`、`/ready` 回 200，一位玩家能登入並收到心跳；CI 的 `e2e` job 最先跑它 |
| `TestPlayerFlow_LoginRollLogoutRelogin` | 登入、載入盤面、擲骰、登出、重登，擲骰後的完整快照在重登後必須相同，繼續擲骰從上次終點出發 |
| `TestPlayerStateful_RandomCommandSequence` | 固定種子隨機混合擲骰、載入、登出再登入，每步檢查不變量（拒絕不改狀態、重登一致）；失敗訊息帶種子與步驟 |

## 冪等、並行與限流

| 測試 | 場景 |
|------|------|
| `TestIdempotency_RollDiceResend` | 同 `RequestID` 重送：同連線與重登後都回放原結果，不多走一步、不多扣骰子；新 `RequestID` 作為對照 |
| `TestConcurrency_PipelinedRollsAreAppliedInOrder` | 不等回覆連送多個擲骰，仍照順序結算，最終盤面等於最後一次成功的擲骰 |
| `TestConcurrency_SameRequestIDSentManyTimesRunsOnce` | 同一個 `RequestID` 連送 10 次只執行一次、只花一顆骰子 |
| `TestConcurrency_BoardCommandsBeyondGateLimitAreDroppedNotQueued` | Gate 盤面指令限流（每連線每秒 10、burst 20）：超額丟棄而非排隊，連線不關閉，狀態只反映有回覆的指令 |

## 作弊與越權

| 測試 | 場景 |
|------|------|
| `TestCheat_BoardCommandBeforeLoginIsIgnored` | 未登入送盤面指令被忽略，之後登入的玩家狀態是全新的 |
| `TestCheat_ForgedServerMessagesCloseConnectionAndLeaveVictimUntouched` | 玩家連線送出冒充 Gate／Central／跨 World 的伺服器內部訊息：連線被關閉，被冒充的玩家連線與狀態不受影響 |
| `TestCheat_CommandFloodClosesConnectionWithoutBreakingState` | 指令洪水在全部回覆前被切斷，旁觀玩家不受影響，洪水玩家重登後快照合法 |

## 故障注入與崩潰恢復

| 測試 | 場景 |
|------|------|
| `TestRecordFault_RabbitMQOutage_NoEventLoss` | 經 `FaultProxy` 切斷 Record 與 RabbitMQ：中斷期間事件留在 broker，恢復後全部存入且不重複 |
| `TestRecordFault_MySQLOutage_NoEventLoss` | 切斷 Record 與 MySQL：寫入失敗的事件放回佇列，恢復後全部存入 |
| `TestCrashRecovery_WorldKilledAfterWriteBehind` | 結算後等過寫回間隔再 `SIGKILL` World：重啟重登的快照與擲骰後相同，並能繼續擲骰 |
| `TestCrashRecovery_WorldKilledRightAfterRoll` | 擲骰剛回覆就殺：恢復的狀態只能是擲骰前或擲骰後之一，不可壞掉或混合 |

名詞與各類測試的白話說明見[測試名詞與類型說明](../30-部署與開發/測試名詞與類型說明.md)。

## 執行方式

完整清單請見 `Makefile` 中 `it-*` 指令群。需要依賴服務時，用 `scripts/integration-deps-up.sh` 起拋棄式依賴並依它印出的環境變數執行，用完 `scripts/integration-deps-up.sh down` 移除。
