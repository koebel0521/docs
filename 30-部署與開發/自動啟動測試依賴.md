# 自動啟動測試依賴

Windows 本機測試可使用：

```powershell
powershell -ExecutionPolicy Bypass -File ./scripts/test.ps1
```

腳本會依序：

1. 確認 Docker CLI 與 Go 可用。
2. 若 Docker Desktop 已安裝但尚未啟動，自動啟動並等待 Docker engine ready。
3. 以 `docker compose up -d` 啟動整份 `docker/compose/compose.deps.yml`（兩個 MySQL、Redis、RabbitMQ，加 Prometheus、Grafana）。
4. 等待 `project-dev-mysql`、`project-dev-mysql-central`、`project-dev-redis`、`project-dev-rabbitmq` 容器通過 healthcheck（逾時 `-HealthTimeoutSeconds`，預設 120 秒）。
5. 執行 `go test -race -shuffle=on ./...`。

腳本**只跑單元測試**，不帶 `-tags integration`；依賴啟動是給會連本機 Redis 等服務的單元測試用。整合測試與 e2e 請用 `make ci-it-pkg`、`make it-test`。

若只需要快速測試、不使用 race detector：

```powershell
powershell -ExecutionPolicy Bypass -File ./scripts/test.ps1 -NoRace
```

若找不到 Docker Desktop 安裝位置，腳本會顯示原因並停止。
