# 自動啟動測試依賴

Windows 本機測試可使用：

```powershell
powershell -ExecutionPolicy Bypass -File ./scripts/test.ps1
```

腳本會依序：

1. 確認 Docker CLI 與 Go 可用。
2. 若 Docker Desktop 已安裝但尚未啟動，自動啟動並等待 Docker engine ready。
3. 啟動 `docker/compose/compose.deps.yml` 的 Redis、MySQL、RabbitMQ。
4. 等待三個服務通過 healthcheck。
5. 執行 `go test -race ./...`。

若只需要快速測試、不使用 race detector：

```powershell
powershell -ExecutionPolicy Bypass -File ./scripts/test.ps1 -NoRace
```

若找不到 Docker Desktop 安裝位置，腳本會顯示原因並停止。
