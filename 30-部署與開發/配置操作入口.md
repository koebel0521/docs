# 配置操作入口

本頁只整理目前可執行的配置操作；完整設計、限制與演進階段請看[bytes 配置統一與熱重載方案](../90-參考附件/方案草稿/bytes配置統一與熱重載方案.md)。

## 發布前檢查

```powershell
go run ./tools/pja configartifact -help
go run ./tools/pja configaudit -help
```

## 發布與回退

```powershell
.\scripts\publish-data-config.ps1 -Help
.\scripts\rollback-data-config-release.ps1 -Help
.\scripts\cleanup-data-config-releases.ps1 -Help
```

`publish-data-config.ps1`、`rollback-data-config-release.ps1`、`cleanup-data-config-releases.ps1`、`initialize-board-topology.ps1`、`migrate-player-variables.ps1` 五支腳本都有 `-Help`（印出 `Get-Help -Detailed`；說明為英文，避免 PowerShell 5.1 讀無 BOM 的 UTF-8 時亂碼）。`rollback-data-config-release.ps1` 的 `-Version` 只在非 `-Help` 時必填。

實際發布前先加 `-DryRun`：`publish-data-config.ps1 -DryRun`（等同 `configartifact -dry-run`）只做來源驗證與換版規則檢查，不寫 releases、不更新 `current.json`，輸出多一行 `dry_run=true`；不可與 `-switch-version`、`-verify-topology-lineage` 併用。未確認 lineage 與當前服務狀態前，不清理歷史 artifact。

## Topology migration

```powershell
.\scripts\initialize-board-topology.ps1 -Help
go run ./tools/pja configartifact -help
```

Topology migration 需要依完整 migration 文件執行，不等同一般熱重載。`initialize-board-topology.ps1` 要求 `-Status` 或 `-MigrateCurrent` 擇一，沒有 `-Apply`。

## Artifact 與 topology 維運

```powershell
.\scripts\publish-data-config.ps1 -TopologyMigration -RequireTopologyMigratable
.\scripts\initialize-board-topology.ps1 -Status -RetentionReport
.\scripts\initialize-board-topology.ps1 -MigrateCurrent
.\scripts\initialize-board-topology.ps1 -Status -RequireMigratable
.\scripts\initialize-board-topology.ps1 -Status -RequireCurrent
.\scripts\backup-data-config-release.ps1 -Root config\data -Version <config-sha>
.\scripts\rollback-data-config-release.ps1 -Root config\data -Version <config-sha>
```

相對的 `-Root`／`-BackupRoot` 一律以倉庫根目錄為基準（與 `publish-data-config` 一致），在子目錄執行也不會切換或清理到錯的根目錄。

清理 release 前先完成 `-RequireCurrent` 檢查；需要縮短 lineage 時，先完成 compaction，再執行 cleanup 的 dry-run 與 `-Apply`。

## Variable migration

```powershell
.\scripts\migrate-player-variables.ps1 -Status -RequireMigratable
.\scripts\migrate-player-variables.ps1 -Help
```

先執行 `-Status` 預檢；正式 migration 前須依方案停止 World 並確認備份與 checkpoint。
