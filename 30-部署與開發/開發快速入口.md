# 開發快速入口

常用開發流程集中在這裡；規範細節請看[開發規則](開發規則.md)；測試類型與名詞請看[測試名詞與類型說明](測試名詞與類型說明.md)。

## 修改 Go 程式碼

```powershell
go tool -modfile=tools/gotools/go.mod golangci-lint fmt <本次修改的.go檔案或目錄>
go test ./...
```

格式基準以 CI 為準：`golangci-lint fmt` 一次套用 `.golangci.yml` 的 gofumpt、goimports、gci（import 分組為標準庫、`local/server`、第三方）。只跑 `goimports -w` 會把本專案 import 放進標準庫群組，被 `make lint`／CI 的 gci 擋下；全樹格式化用 `make fmt`。本機 `CLAUDE.md`（不在版控）若仍要求 `goimports -w`，跑完後再補一次 `golangci-lint fmt`。

## 本機啟動

`scripts/dev-up.sh` 只編譯並啟動七個服務（Central、Record、Lobby、Chat、World、Gate、User；先 `go build` 到 `.run/dev-up/bin/` 再執行，Ctrl+C 會等全部服務優雅關機），**不啟動** MySQL、Redis、RabbitMQ；沒有依賴時各服務會因連不上而啟動失敗。順序固定是先依賴、再服務：

```bash
./scripts/docker-deps-up.sh   # 或 make deps-up
./scripts/dev-up.sh
```

直接用 compose 啟動依賴時：

```bash
docker compose -f docker/compose/compose.deps.yml up -d
```

啟動後登入冒煙：`printf 'login 0 alice <password>\n' | APP_CONFIG=config/dev/user.yaml go run ./tools/user`；新帳號必須帶密碼，不帶密碼 Central 回 `AuthWrongPassword`。

Docker 測試資料重置可選擇是否重新啟動依賴：

```bash
make deps-reset-only # 清除後保持停止
make deps-reset-up   # 清除後重新啟動
```

兩種命令都會刪除 `compose.deps.yml` 的 MySQL、Redis、RabbitMQ 資料卷，無法復原；僅用於 Docker 測試環境。本機安裝的依賴使用：

```bash
make deps-reset-local
```

本機重置僅允許預設測試埠（MySQL `13306`、Redis `16379`、RabbitMQ 管理 API `35672`），清除 MySQL `project`、Redis DB 0 和 RabbitMQ `record.events` 佇列；需安裝 `mysql` 與 `redis-cli` 用戶端。

## 驗證

| 需求 | 指令 |
| --- | --- |
| 單元測試 | `make test` |
| 整合測試（全部，需先 `make deps-up`） | `make ci-it` |
| 套件內整合測試（與 CI 相同範圍） | `make ci-it-pkg` |
| 快速整合測試 | `make it-fast` |
| 冒煙測試（需依賴服務） | `go test -tags=integration -count=1 -run TestSmoke_ ./integration/` |
| 拋棄式整合測試依賴 | `./scripts/integration-deps-up.sh`（用完加 `down`） |
| MR 前的效能退化檢查 | `make bench-gate BASE=develop` |
| 備份還原演練（需 docker） | `make backup-drill` |
| 靜態檢查 | `make lint` |
| 漏洞掃描 | `make vuln` |
| 文件連結檢查 | `make docs-check` |
| Race 測試 | `go test -race -shuffle=on -timeout=5m ./...` |

## 提交前

1. 執行與修改範圍相符的測試。
2. Go 檔案先執行 `go tool -modfile=tools/gotools/go.mod golangci-lint fmt <檔案>`（或 `make fmt`）。
3. 確認 `git diff --check` 與 `make docs-check` 通過。
4. Commit 使用中文，格式見[開發規則](開發規則.md#commit-慣例)。
