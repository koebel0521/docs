# 腳本總覽

這頁只做索引。每支腳本的使用流程、前提、參數與失敗判讀，改看對應的獨立文檔。

## 使用原則

- 先找對應腳本文檔，再跑腳本。
- 能 `-DryRun`、`-Check`、`-Quiet` 就先看一遍。
- 會改環境、落檔、發版、封存的腳本，先看相關文檔再動手。
- `scripts/private/p0-daily-check.ps1` 是統一入口，不是取代各腳本文檔。
- `scripts/private/` 已被 `.gitignore` 排除、不在版控（p0-daily-check、alert-selfheal、regression-gate、fault-archive、player-incident-snapshot、check-s2s-docker）；乾淨 clone 沒有這些腳本，CI 與版控內腳本不得依賴它們。

## 監控與文件

- 整理 Go imports 與格式：`make fmt`（`go tool -modfile=tools/gotools/go.mod golangci-lint fmt`，與 CI、pre-commit 同一套 formatter 與版本；原 `scripts/goimports.ps1` 已移除）。
- [`scripts/monitoring-up.sh`](./scripts/監控啟動.md)
- [`scripts/monitoring-smoke.ps1`](./scripts/監控冒煙測試.md)
- [`scripts/docs-drift-check.ps1`](./scripts/文件漂移檢查.md)
- [`scripts/configcheck.ps1`](./scripts/配置檢查.md)
- [`scripts/sync-data-config.ps1`](../../scripts/sync-data-config.ps1)：把 `PJA-Config` 的產物同步到 `pkg/dataconfig/generated` 與 `config/data`；日常建議用 `scripts/Build-And-Sync-Config.ps1`，它會先建置再同步。
- [`scripts/sync-protocol.ps1`](../../scripts/sync-protocol.ps1)：從 `PJA-Protocol` 產生並同步 Client 與 S2S 協議到 `pkg/protocol/wire`，並匯入 `pkg/msg` 的訊息包裝；`-Check` 只比對不寫入。
- [`scripts/publish-data-config.ps1`](./配置Artifact發布與回退.md)：驗證並發布 bytes artifact，支援拓樸 migration、lineage 驗證與壓縮。
- [`scripts/initialize-board-topology.ps1`](./配置Artifact發布與回退.md)：初始化、檢查與離線搬遷玩家盤面拓樸版本。
- [`scripts/backup-data-config-release.ps1`](./配置Artifact發布與回退.md)：備份 `current.json` 與指定 release。
- [`scripts/rollback-data-config-release.ps1`](./配置Artifact發布與回退.md)：經 Server 驗證後切換指定 release。
- [`scripts/cleanup-data-config-releases.ps1`](./配置Artifact發布與回退.md)：列出或清理已脫離 lineage 的 release。

## 其他腳本

- [`scripts/core-test-up.ps1`](../../scripts/core-test-up.ps1)：以 `compose.core-test.yml` 起 Central、World、Gate 與依賴，並為各服務開日誌視窗。
- [`scripts/reset-local-deps.ps1`](../../scripts/reset-local-deps.ps1)：`make deps-reset-local` 的實作；只允許本機 `13306` MySQL。
- [`scripts/ci-deploy.sh`](./Docker發版流程.md)：GitLab deploy job 呼叫的部署腳本，失敗自動回退 image 與設定 artifact；`scripts/migrate-prod.sh` 轉呼叫 `deps/PJA-Database/scripts/migrate-prod.sh`。
- [`scripts/ci-patch-coverage.sh`](./開發規則.md)：MR 改動行覆蓋率檢查。
- [`scripts/migrate-player-variables.ps1`](./配置操作入口.md)：玩家變數 migration。
- [`scripts/gen-pgo-profile.ps1`](../../scripts/gen-pgo-profile.ps1)：產生 `default.pgo`，可用 `-ProductionProfile` 併入正式 pprof。
- [`scripts/get-failed-pipeline-logs.ps1`](../../scripts/get-failed-pipeline-logs.ps1)：下載 GitLab 失敗 pipeline 的 job log（`-PipelineId`、`-Token`、`-OutputDirectory`，預設 `.\failed-pipeline-logs`）。
- S2S 機密（流程見 [S2S身份驗證](./S2S身份驗證.md)）：`new-s2s-dev-secrets.ps1`、`check-s2s-dev-secrets.ps1`、`update-s2s-gate-secret.ps1`、`invoke-s2s-maintenance.ps1`、`new-s2s-maintenance-task.ps1`、`check-s2s-distribution.py`、`check-s2s-maintenance.py`；底層 `s2s-distribute.py`、`s2s-renew-certificates.py`、`s2s-secret-receiver.py` 由維護入口呼叫，不直接執行。
