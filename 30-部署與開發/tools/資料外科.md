# `tools/datasurgeon`

## 作用
修 Redis 內的衍生資料。

## 目的
清掉壞 route、player store、dead-letter 這類 derived data。

## 流程
1. 先選 `-mode`。
2. 不加 `-apply` 先看差異（沒有 `-dry-run` 旗標，預設就是只列出）。
3. 確認後以 `-apply -confirm` 才真的修。

## 主要參數
- `-mode`：`route`（預設）、`playerstore`、`deadletter`
- `-redis`
- `-db`
- `-timeout`
- `-apply`：套用修正；必須加 `-confirm`
- `-confirm`
- `-limit`
- `-world-id`
- `-purge-malformed`

## 常用指令
- `go run ./tools/datasurgeon -mode route`
- `go run ./tools/datasurgeon -mode route -apply -confirm`
