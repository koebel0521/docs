# `tools/datasurgeon`

## 作用
修 Redis 內的衍生資料。

## 目的
清掉壞 route、player store、dead-letter 這類 derived data。

## 流程
1. 先選 `-mode`。
2. 不加 `-apply` 先看差異。
3. 確認後才真的修。

## 主要參數
- `-mode`
- `-redis`
- `-db`
- `-apply`
- `-limit`
- `-world-id`
- `-purge-malformed`

## 常用指令
- `rtk go run ./tools/datasurgeon -mode route -dry-run`
