# `tools/supportdiag`

## 作用
查 account、route、session、dead-letter、protocol。

## 目的
客服或值班快速收斂單帳號問題。

## 流程
1. 先給 `-account` 或 `-trace-id / -request-id`。
2. 必要時再加 `-output`。
3. 視需要把結果落檔。

## 主要參數
- `-account`
- `-trace-id`
- `-request-id`
- `-redis`
- `-db`
- `-central`
- `-gate`
- `-world`
- `-lobby`
- `-output`
- `-output` (json|json-compact)
- `-limit`
- `-timeout`

## 常用指令
- `rtk go run ./tools/supportdiag -account alice -output .\.run\supportdiag.json`
