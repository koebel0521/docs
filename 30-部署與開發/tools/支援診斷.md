# `tools/supportdiag`

## 作用
查 account、route、session、dead-letter、protocol。

## 目的
客服或值班快速收斂單帳號問題。

## 流程
1. 先給 `-account` 或 `-trace-id / -request-id`。
2. 必要時再加 `-output`。
3. 視需要把結果落檔。

## 主要參數
- `-account`
- `-trace-id`
- `-request-id`
- `-redis`
- `-db`
- `-central`
- `-gate`
- `-world`
- `-lobby`
- `-output`：結果寫入的檔案路徑；未指定時輸出到標準輸出
- `-output-format`：輸出格式，`json`（預設）或 `json-compact`
- `-limit`
- `-timeout`

## 部分失敗
- 只有帳號讀不出或欄位格式錯才整體失敗。
- 路由讀不出或格式錯記在 `route.error`；Gate session 診斷失敗記在 `session.error`；Lobby 與死信失敗記在各自的 `error`。其餘已讀資料照常輸出。

## 常用指令
- `go run ./tools/supportdiag -account alice -output .\.run\supportdiag.json`
