# `tools/coldstorage`

## 作用
把舊 dead-letter、audit cache、snapshot 類 key 匯出成 JSONL。

## 目的
做冷資料封存與可選 purge。

## 流程
1. 先 `-dry-run` 看 manifest。
2. 確認輸出檔與 pattern。
3. 需要時再 `-purge`。

## 主要參數
- `-redis`
- `-db`
- `-output`
- `-pattern`
- `-purge`
- `-dry-run`

## 常用指令
- `rtk go run ./tools/coldstorage -output .\.run\coldstorage\export.jsonl -dry-run`
