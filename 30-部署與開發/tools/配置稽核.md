# `tools/configaudit`

## 作用
檢查 `.env.prod.example`、compose、prod config、Prometheus / Grafana。

## 目的
先抓環境分叉，再查 runtime 問題。

## 流程
1. 先跑審核。
2. 再看哪一份設定不一致。
3. 把不一致的地方修回來。

## 主要參數
- `-env`
- `-compose-full`
- `-compose-prod`
- `-prod-central`
- `-prod-world`
- `-prod-gate`
- `-prod-lobby`
- `-prometheus`
- `-datasource`

## 常用指令
- `rtk go run ./tools/configaudit`
