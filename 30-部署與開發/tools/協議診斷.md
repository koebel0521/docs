# `tools/protocoldiag`

## 作用
合併 `Central / Gate / World` 的 `/diag/protocol`。

## 目的
一次看同一條 `trace_id` 或 `request_id` 的送收鏈。

## 流程
1. 給 `-trace-id` 或 `-request-id`。
2. 比對三台服務輸出。
3. 找出哪一段開始不一致。

## 主要參數
- `-trace-id`
- `-request-id`
- `-central`
- `-gate`
- `-world`
- `-limit`
- `-timeout`

## 常用指令
- `rtk go run ./tools/protocoldiag -trace-id 123`
