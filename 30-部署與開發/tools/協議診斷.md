# `tools/private/protocoldiag`

> 私人工具：原始碼在本機 `tools/private/`（被 `.gitignore` 忽略、不在版控），乾淨 clone 沒有這個工具；沒有時改用各服務診斷埠的 `/ready`、`/metrics`、`/diag/*`（見[SLO 值班流程](../../20-排障與監控/SLO值班流程.md#沒有私人工具時)）。

## 作用
合併 `Central / Gate / World` 的 `/diag/protocol`。

## 目的
一次看同一條 `trace_id` 或 `request_id` 的送收鏈。

## 流程
1. 給 `-trace-id` 或 `-request-id`。
2. 比對三台服務輸出。
3. 找出哪一段開始不一致。

## 主要參數
- `-trace-id`
- `-request-id`
- `-central`
- `-gate`
- `-world`
- `-limit`
- `-timeout`
- `-output`：輸出格式，`json`（預設）或 `json-compact`

## 常用指令
- `go run ./tools/private/pja protocoldiag -trace-id 123`
