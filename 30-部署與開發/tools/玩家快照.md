# `tools/playersnapshot`

## 作用
匯出單一玩家快照。

## 目的
單帳號事故時保留可攜證據。

## 流程
1. 給 `-account` 與 `-output`。
2. 必要時一起保留 gate / lobby 狀態。
3. 寫出 snapshot 檔。

## 主要參數
- `-account`
- `-redis`
- `-db`
- `-gate`
- `-lobby`
- `-output`
- `-timeout`
- `-output` (json|json-compact)

## 常用指令
- `rtk go run ./tools/playersnapshot -account alice -output .\.run\player-snapshot.json`
