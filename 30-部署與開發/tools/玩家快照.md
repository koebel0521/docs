# `tools/playersnapshot`

## 作用
匯出單一玩家快照。

## 目的
單帳號事故時保留可攜證據。

## 流程
1. 給 `-account` 與 `-output`。
2. 必要時一起保留 gate / lobby 狀態。
3. 寫出 snapshot 檔。

## 主要參數
- `-account`
- `-redis`
- `-db`
- `-gate`
- `-lobby`
- `-output`：快照寫入的檔案路徑；未指定時輸出到標準輸出
- `-output-format`：輸出格式，`json`（預設）或 `json-compact`
- `-timeout`

## 部分失敗
- 只有帳號讀不出或欄位格式錯才整體失敗。
- 路由讀不出或格式錯記在 `route.error`；Gate 診斷失敗記在 `gate.error`；Lobby 與死信失敗記在各自的 `error`。其餘已讀資料照常輸出。

## 常用指令
- `go run ./tools/playersnapshot -account alice -output .\.run\player-snapshot.json`
