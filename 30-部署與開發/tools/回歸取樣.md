# `tools/private/regressionsample`

> 私人工具：原始碼在本機 `tools/private/`（被 `.gitignore` 忽略、不在版控），乾淨 clone 沒有這個工具；沒有時改用各服務診斷埠的 `/ready`、`/metrics`、`/diag/*`（見[SLO 值班流程](../../20-排障與監控/SLO值班流程.md#沒有私人工具時)）。

## 作用
管理回歸樣本。

## 目的
保留可重放的 login / logout / recovery fixture。

## 流程
1. 先 `-validate`。
2. 需要時再 `-list`。
3. 要看單筆就指定 `-sample`。

沒給任何模式旗標時印 usage 並以退出碼 2 結束（腳本誤用不會被當成功）。

## 主要參數
- `-dir`
- `-list`
- `-validate`
- `-sample`

## 常用指令
- `go run ./tools/private/pja flow sample -validate`
