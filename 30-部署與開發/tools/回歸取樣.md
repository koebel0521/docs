# `tools/regressionsample`

## 作用
管理回歸樣本。

## 目的
保留可重放的 login / logout / recovery fixture。

## 流程
1. 先 `-validate`。
2. 需要時再 `-list`。
3. 要看單筆就指定 `-sample`。

沒給任何模式旗標時印 usage 並以退出碼 2 結束（腳本誤用不會被當成功）。

## 主要參數
- `-dir`
- `-list`
- `-validate`
- `-sample`

## 常用指令
- `go run ./tools/private/pja flow sample -validate`
