# `tools/capacityforecast`

## 作用
讀 `loadtest` baseline 推估容量 headroom。

## 目的
知道目前可承載玩家數與退化因子。

## 流程
1. 先準備 baseline。
2. 再指定 target p95 / queue 門檻。
3. 輸出容量預估。

## 主要參數
- `-baseline`
- `-target-p95-ms`
- `-target-queue-depth`
- `-json`

## 常用指令
- `rtk go run ./tools/capacityforecast -baseline .\.run\loadtest-baseline.json`
