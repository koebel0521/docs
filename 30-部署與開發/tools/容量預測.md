# `tools/private/capacityforecast`

> 私人工具：原始碼在本機 `tools/private/`（被 `.gitignore` 忽略、不在版控），乾淨 clone 沒有這個工具；沒有時改用各服務診斷埠的 `/ready`、`/metrics`、`/diag/*`（見[SLO 值班流程](../../20-排障與監控/SLO值班流程.md#沒有私人工具時)）。

## 作用
讀 `loadtest` baseline 推估容量 headroom。

## 目的
知道目前可承載玩家數與退化因子。

## 流程
1. 先準備 baseline。
2. 再指定 target p95 / queue 門檻。
3. 輸出容量預估。

## 主要參數
- `-baseline`
- `-target-p95-ms`
- `-target-queue-depth`
- `-output`：輸出格式，`text`（預設）或 `json`

## 常用指令
- `go run ./tools/private/pjaload capacityforecast -baseline .\.run\loadtest-baseline.json`
