# `tools/dephealth`

## 作用
一次看 readiness、service class、queue 深度。

## 目的
值班先抓整體健康，再決定要不要往下看細節。

## 流程
1. 跑一次 health 掃描。
2. 先看 `critical / core / peripheral`。
3. 看到 `degraded` 再往下查 queue 或 async failure。

## 主要參數
- `-timeout`
- `-json`
- `-fail-on-class`
- `-fail-on-status`

## 常用指令
- `rtk go run ./tools/dephealth --fail-on-class critical,core --fail-on-status down,degraded`
