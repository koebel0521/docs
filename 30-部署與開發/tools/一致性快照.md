# `tools/private/consistencysnapshot`

> 私人工具：原始碼在本機 `tools/private/`（被 `.gitignore` 忽略、不在版控），乾淨 clone 沒有這個工具；沒有時改用各服務診斷埠的 `/ready`、`/metrics`、`/diag/*`（見[SLO 值班流程](../../20-排障與監控/SLO值班流程.md#沒有私人工具時)）。

## 作用
落一份 `debug.Endpoints()` 全部服務（Central、Gate、World、User、Lobby、Record、Chat）的 readiness 與關鍵 metrics 快照；在線人數以 `world_id` 加總，每個 World 一筆。

## 目的
發版、事故、封存時保留現場。

## 流程
1. 指定 `-output`。
2. 必要時加 endpoint gate。
3. 寫出快照檔。

## 主要參數
- `-prometheus`
- `-output`：輸出檔路徑；未指定時輸出到標準輸出
- `-fail-on-endpoint-down`
- `-timeout`：HTTP 逾時，預設 5 秒

## 常用指令
- `go run ./tools/private/pja consistencysnapshot -output .\.run\consistency-snapshot.json`
