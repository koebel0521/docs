# `tools/consistencysnapshot`

## 作用
落一份 `Central / Gate / World / User / Lobby` readiness 與關鍵 metrics 快照。

## 目的
發版、事故、封存時保留現場。

## 流程
1. 指定 `-output`。
2. 必要時加 endpoint gate。
3. 寫出快照檔。

## 主要參數
- `-prometheus`
- `-output`
- `-fail-on-endpoint-down`

## 常用指令
- `rtk go run ./tools/consistencysnapshot -output .\.run\consistency-snapshot.json`
