# `tools/private/staterepair`

> 私人工具：原始碼在本機 `tools/private/`（被 `.gitignore` 忽略、不在版控），乾淨 clone 沒有這個工具；沒有時改用各服務診斷埠的 `/ready`、`/metrics`、`/diag/*`（見[SLO 值班流程](../../20-排障與監控/SLO值班流程.md#沒有私人工具時)）。

## 作用
修 session、route、world drain、account lock。

## 目的
只修可重建的 derived state，不碰 source of truth。

## 流程
1. 先 `-dry-run` 看計畫；不加 `-dry-run` 時必須加 `-confirm` 才會連線改寫（含 `-rollback`）。
2. 視需要加 `-clear-route`、`-clear-lock`、`-clear-session`、`-repair-session`、`-drain-world`、`-undrain-world`。
3. 需要回滾時再用 `-rollback` 與 `-backup-file`。

## 主要參數
- `-redis`
- `-db`
- `-timeout`
- `-gate`
- `-account`
- `-user-id`
- `-world-id`
- `-clear-route`
- `-clear-lock`
- `-clear-session`
- `-repair-session`
- `-drain-world`
- `-undrain-world`
- `-dry-run`
- `-confirm`：確認實際執行
- `-rollback`
- `-backup-file`

## 行為注意
- `-drain-world`、`-undrain-world` 只接受正整數 World ID；0 或負數直接拒絕。
- 帳號快取的 uid 必須是正整數，0 與負數視為損毀並拒絕，不刪除任何東西。
- `-repair-session` 呼叫 Gate 的 reconcile 後，若回應的 `issuesAfter` 仍有殘留，工具以非 0 結束並回報 `gate repair incomplete`，不會顯示成功。回應採嚴格解碼：空回應、`{}`、未知欄位與尾端多餘資料都視為錯誤。

- 備份擷取時 key 在 `TYPE` 與 `PTTL` 之間剛好過期（`PTTL` 回 -2），該 key 記為 `none` 型別條目（視為不存在），不會寫入無效 TTL 讓整份備份無法 `-rollback`。

## 常用指令
- `go run ./tools/private/pja staterepair -clear-route -account alice -user-id 7 -dry-run`
- `go run ./tools/private/pja staterepair -clear-route -account alice -user-id 7 -confirm`
