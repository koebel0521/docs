# `tools/staterepair`

## 作用
修 session、route、world drain、account lock。

## 目的
只修可重建的 derived state，不碰 source of truth。

## 流程
1. 先 `-dry-run` 看計畫。
2. 視需要加 `-clear-route`、`-clear-lock`、`-clear-session`、`-repair-session`、`-drain-world`、`-undrain-world`。
3. 需要回滾時再用 `-rollback` 與 `-backup-file`。

## 主要參數
- `-redis`
- `-db`
- `-gate`
- `-account`
- `-user-id`
- `-world-id`
- `-clear-route`
- `-clear-lock`
- `-clear-session`
- `-repair-session`
- `-drain-world`
- `-undrain-world`
- `-dry-run`
- `-rollback`
- `-backup-file`

## 常用指令
- `rtk go run ./tools/staterepair -clear-route -account alice -user-id 7 -dry-run`
