# `tools/private/loadtest`

> 私人工具：原始碼在本機 `tools/private/`（被 `.gitignore` 忽略、不在版控），乾淨 clone 沒有這個工具；沒有時改用各服務診斷埠的 `/ready`、`/metrics`、`/diag/*`（見[SLO 值班流程](../../20-排障與監控/SLO值班流程.md#沒有私人工具時)）。

## 作用
模擬大量玩家登入、登出、重連與心跳。

## 目的
觀察長跑下的 latency、queue、reconnect、error 是否退步。

## 流程
1. 先短跑 smoke。
2. 要看長跑就開 `-soak`。
3. 要比 baseline 就先寫 baseline，再拿新結果對照。

## 主要參數
- `-gate`：預設 `127.0.0.1:62001`；非 loopback 位址需加 `-allow-remote`
- `-allow-remote`：允許打非本機 Gate（會在該環境建立真實的 `loadtest_*` 帳號）
- `-client-contract`：版本握手 `HelloRequest` 帶的 client contract；預設 0 表示沿用 `pkg/release/release.json`（由 `pkg/release/releasehello` 組出 `HelloRequest`），指定與 Server 不同的值可測試被拒絕的情況
- `-n`：虛擬玩家數，至少 1
- `-duration`：必須為正
- `-ramp`：爬坡期間也可用 Ctrl-C 中斷；被中斷時報告以實際經過時間計算，且不寫入 `-write-baseline`
- `-hb`：心跳間隔，必須為正
- `-soak`：長跑模式，工作階段結束或連線被中斷後等 `-cooldown` 再重新登入，所以也能用來量中斷後的自動重連
- `-session`：soak 模式每個工作階段的常駐時間（預設 45 秒）
- `-cooldown`：soak 模式下一次登入前的等待（預設 2 秒）
- `-source-ips`：以逗號分隔的本機來源 IP，玩家輪流綁定（例如 `127.0.2.2,127.0.2.3`）。Gate 對單一來源 IP 有連線數、接入速率與登入嘗試限流，同機壓測不加會卡在約 30 人；1000 人建議至少 32 個
- `-baseline`
- `-write-baseline`
- `-baseline-metrics-url`
- `-baseline-tolerance`

## 常用指令
- `go run ./tools/private/pjaload loadtest -gate 127.0.0.1:62001 -n 100 -duration 30s`
- `go run ./tools/private/pjaload loadtest -gate 127.0.0.1:62001 -source-ips 127.0.2.2,127.0.2.3,… -n 1000 -ramp 40s -duration 60s`

## 注意
- 玩家帳號固定為 `loadtest_NNNNNN`，沒有密碼；新帳號現在必須帶密碼，所以這個工具只能用既有帳號登入。要建立新帳號請用 `cmdload`、`soakload`、`gameload`、`chatload`，並設環境變數 `RL_PASSWORD`（見[壓測手冊](../壓測手冊.md)）。
- 登出只在 Gate 回 `AuthSuccess` 時計為成功；以其他碼回覆（例如被登出）計入錯誤。
- 登入遇 Central 同時登入上限（code 9）會自動重試，報告中的 `loginRetry` 就是這個次數。
