# `tools/flowreplay`

## 作用
重放 login / logout / recovery fixture。

## 目的
重現事故或驗證回歸樣本。

## 流程
1. 先載入 fixture。
2. 視需要給 gate 位址。
3. `-dry-run` 時只驗證 fixture。

## 主要參數
- `-fixture`
- `-gate`
- `-dry-run`

## 常用指令
- `rtk go run ./tools/flowreplay -fixture .\samples\login_logout_recovery.json -dry-run`
