# `scripts/change-approval.ps1`

## 作用
寫 release / config / schema 的審批 stamp。

## 目的
讓發版前有可追的批准點。

## 流程
1. 指定 `-ChangeType`（必填，第十一輪；原本漏寫時會寫出 `change_type=` 的無效戳記並回 0，到 `docker-release.sh` 才以 stamp mismatch 拒絕）、`-Target`、`-Owner`。
2. 印出 checklist。
3. 寫入 `.run/change-approval/current.txt`。

## 主要參數
- `-ChangeType`
- `-Target`
- `-Owner`
- `-ValidHours`（預設 24 小時，上限 168）：戳記效期；戳記綁定目前 `HEAD` commit，換 commit 或過期就失效，`docker-release.sh` 發版成功後作廢；舊格式（沒有 commit／效期欄位）不接受
- `-DryRun`
