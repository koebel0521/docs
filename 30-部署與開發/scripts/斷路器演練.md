# `scripts/circuit-breaker-drill.ps1`

## 作用
對 Redis、MySQL、World 做 pause / resume 演練。

## 目的
確認系統在依賴中斷時會正確降級，恢復後也能回來。

## 流程
1. 依序 pause 目標服務。
2. 驗證 pause 期間健康檢查應該失敗。
3. 再 resume。
4. 必要時再跑 smoke。

## 主要參數
- `-ComposeFile`
- `-EnvFile`
- `-Targets`
- `-SkipSmoke`
- `-ConfirmDrill`：非 `-DryRun` 時必須加，否則拒絕執行（預設 compose 是 `docker/compose/compose.full.yml`，env 檔是 `.env.prod`，會 pause 該堆疊的 Redis／MySQL／World，不要對正式環境誤跑）
- `-DryRun`

暫停後任何一步失敗都會解除暫停（`finally`），MySQL 健康檢查以容器內環境變數帶密碼，不再寫死在命令列。
