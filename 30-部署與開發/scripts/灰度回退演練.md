# `scripts/canary-failback-drill.ps1`

## 作用
驗證 canary 切進去後能回切穩定 world。

## 目的
確認 slice 調成 0 後，流量能退回 fallback 路徑。

## 流程
1. 讀 `central.yaml` 裡的 traffic slice 設定。
2. 找一個可命中的 canary account。
3. 模擬切進 canary，再模擬 cutback。
4. 驗證回切後不再命中 canary world。

## 主要參數
- `-ConfigPath`
- `-Account`
- `-StableWorldID`
- `-CanaryWorldID`
- `-CanaryPercent`
- `-DryRun`
