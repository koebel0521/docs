# `scripts/upgrade-compatibility-drill.ps1`

## 作用
驗證 rolling upgrade 與 rollback 相容性。

## 目的
確認舊新混跑時，服務還能維持可用。

## 流程
1. 指定 `-NewTag`。
2. 依 `central -> world -> gate` 順序升級。
3. 必要時再 rollback。
4. 可選擇加 monitoring 驗證。

## 主要參數
- `-ComposeFile`
- `-EnvFile`
- `-NewTag`
- `-Rollback`
- `-CheckMonitoring`
- `-NoLock`
- `-DryRun`
