# `scripts/monitoring-smoke.ps1`

## 作用
驗證 Grafana / Prometheus / datasource / dashboard 是否真的 provision 完成。

## 目的
避免監控容器起來了，但面板或資料源其實沒接好。

## 流程
1. 等 Prometheus health endpoint。
2. 等 Grafana health endpoint。
3. 確認 Grafana 有 `Prometheus` datasource。
4. 確認 dashboard `game-backend-overview` 已存在。

## 主要參數
- `-GrafanaBaseUrl`
- `-PrometheusBaseUrl`
- `-GrafanaUser`
- `-GrafanaPassword`
- `-DashboardUid`
- `-MaxAttempts`
- `-SleepSeconds`
