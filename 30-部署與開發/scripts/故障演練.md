# `scripts/fault-drill.ps1`

## 作用
固定打 async fault。

## 目的
驗證 retry、dead-letter、metrics 的收斂行為。

## 流程
1. 開啟指定 fault 注入。
2. 對 World 送出 grant item。
3. 等待對應的 retry / ack failure 指標出現。
4. 依 expected outcome 判定通過與否。

## 主要參數
- `-PlayerID`
- `-ItemID`
- `-Quantity`
- `-FaultName`
- `-ExpectedOutcome`
- `-DryRun`
