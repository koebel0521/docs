# `scripts/p0-daily-check.ps1`

## 作用
日常檢查與維運的統一入口。

## 目的
把監控、告警、診斷、修復、演練、發版前檢查收成同一把刀。

## 流程
1. 選 `-Mode`。
2. 必要時先跑 `-DryRun`。
3. 再帶 mode 專屬參數正式執行。
4. 腳本會依 mode 轉呼叫其他 `scripts/` 或 `tools/`。

## 主要參數
- `-Mode`
- `-DryRun`
- `-SkipDephealthGate`
- `-SkipRegressionGate`
- `-SkipAlertDrill`
- `-SkipMonitoringSmoke`
- `-RunFailoverDrill`
