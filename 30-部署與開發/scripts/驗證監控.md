# `scripts/validate-monitoring.py`

## 作用
檢查 monitoring 文件與 provisioning 設定是否對齊。

## 目的
提前抓出 docs、compose、Grafana、Prometheus 的漂移。

## 流程
1. 確認監控相關檔案都存在。
2. 檢查 dashboard UID、標題與關鍵 panel。
3. 檢查 datasource、dashboard provisioning 與 alert rules。
4. 檢查 `本機監控.md` 與 `README.md` 是否仍有正確入口。

## 主要參數
- 無。
