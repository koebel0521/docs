# `scripts/dev-up.sh`

## 作用
在本機產生開發用設定，並啟動開發服務。

## 目的
讓 GoLand 或本機除錯有固定的 app 入口與設定檔。

## 流程
1. 建立 `.run/dev-up/` 的 config 與 logs 目錄。
2. 寫入 `central / world / gate / user / record` 設定檔。
3. 之後再由後續啟動流程使用這些設定。

## 主要參數
- 透過環境變數控制，例如 `MYSQL_HOST`、`MYSQL_PORT`、`MYSQL_USERNAME`、`MYSQL_PASSWORD`、`MYSQL_DBNAME`、`RABBITMQ_URL`、`RUN_USER_APP`、`RUN_RECORD_APP`
