# `scripts/protocol-gate.ps1`

## 作用
跑 Client 版本握手（Hello）的 integration gate。

## 目的
確認版本相符放行、不相符要求更新並斷線、未 Hello 就送訊息會被斷線。

## 流程
1. 非 `-DryRun` 時先跑 `sync-protocol.ps1 -Check` 確認協定生成物與子模組一致。
2. 以 `go test -v -tags integration -run '^TestGateVersionHandshake_' ./integration` 執行 3 個 Hello 握手測試（原本指向的版本鎖／黑名單測試已刪除，會空跑綠燈）。
3. 頂層通過的測試數必須剛好是 3，0 個或少於預期都以失敗結束（`scripts/lib/GoTestGate.ps1`）。

## 主要參數
- `-DryRun`
