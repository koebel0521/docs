# `scripts/backup-restore-drill.sh`

## 作用
在臨時容器上演練 MySQL / Redis 備份與還原。

## 目的
先驗證備份還原流程，再碰正式環境。

## 流程
1. 建立臨時 MySQL / Redis 容器與 volume。
2. 寫入測試資料；Redis 另外執行 `SAVE`，讓資料落到資料卷。
3. 匯出備份。
4. 停掉目標 Redis，還原到另一組 volume 後再啟動，從資料卷載入並驗證資料。

演練腳本自己實作備份還原步驟，沒有呼叫 `docker-backup-*.sh`、`docker-restore-*.sh`；正式腳本的行為另以其檔案說明為準。在 Windows Git Bash 執行會自動關閉路徑轉換（`MSYS_NO_PATHCONV=1`）。

## 主要參數
- 透過環境變數控制：`RUN_DIR`、`MYSQL_IMAGE`、`REDIS_IMAGE`、`MYSQL_PASSWORD`、`MYSQL_DATABASE`
