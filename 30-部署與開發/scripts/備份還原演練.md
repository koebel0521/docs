# `scripts/backup-restore-drill.sh`

## 作用
在臨時容器上演練 MySQL / Redis 備份與還原。

## 目的
先驗證備份還原流程，再碰正式環境。

## 流程
1. 建立臨時 MySQL / Redis 容器與 volume。
2. 寫入測試資料。
3. 匯出備份。
4. 還原到另一組 volume，並驗證資料。

## 主要參數
- 透過環境變數控制：`RUN_DIR`、`MYSQL_IMAGE`、`REDIS_IMAGE`、`MYSQL_PASSWORD`、`MYSQL_DATABASE`
