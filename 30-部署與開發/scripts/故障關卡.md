# `scripts/fault-gate.ps1`

## 作用
跑 World grant item async fault 的單元測試關卡（不是 integration test）。

## 目的
確認 retry、invalid payload、dead-letter 與 budget 邏輯都正常。

## 流程
1. 執行 `./cmd/world/internal/gm` 內指定的五個 `TestGrantItemQueue*` **單元測試**（不帶 integration tag，不起容器，也不連線）：`InjectedGrantFailureSchedulesRetry`、`ProcessValDeadLettersInvalidPayload`、`RequeuesFailedCommand`、`DeadLettersAfterMaxAttempts`、`DeadLettersAfterBudgetExpires`。
2. 驗證故障注入與 dead-letter 行為。
3. 以 `go test -v` 執行，頂層通過的測試數必須剛好是 5；測試改名或刪除導致 0 個測試時以失敗結束，不會空跑綠燈。

## 主要參數
- `-DryRun`
