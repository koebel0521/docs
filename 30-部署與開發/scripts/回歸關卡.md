# `scripts/regression-gate.ps1`

## 作用
用 soak 型 loadtest 驗證 baseline regression。

## 目的
確認長跑行為沒有比 baseline 退步。

## 流程
1. 指定 baseline 路徑。
2. 確認 baseline 檔存在。
3. 跑 `tools/loadtest -soak`。
4. 比對結果與 baseline。

## 主要參數
- `-GateAddr`
- `-Players`
- `-Duration`
- `-Session`
- `-Cooldown`
- `-BaselinePath`
- `-BaselineMetricsURL`
- `-DryRun`
