# `scripts/failover-gate.ps1`

## 作用
跑 failover 相關的 integration gate。

## 目的
確認 pending login 遇到 central / gate / world 重啟時，使用者可以重試。

## 流程
1. 執行指定的 integration test。
2. 驗證三種重啟路徑都能通過。
3. 以 `go test -v` 執行，頂層通過的測試數必須剛好是 3；測試改名或刪除導致 0 個測試時以失敗結束，不會空跑綠燈。

## 主要參數
- `-DryRun`
