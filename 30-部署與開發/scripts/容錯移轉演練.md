# `scripts/failover-drill.ps1`

## 作用
逐個重啟 `central -> world -> gate -> chat -> lobby -> record`（可用 `-Services` 指定），驗證 failover。

## 目的
確認單一服務重啟後，整體鏈路仍能恢復。

## 流程
1. 檢查 compose 與 env。
2. 依序 stop / up 每個服務。
3. 每步都等 `ready` endpoint。
4. 帶 `-CheckMonitoring` 時，每個服務重啟並 ready 之後都會跑一次 production smoke（失敗即中止）；沒帶就只檢查 ready。

`ready` 在容器內以映像的 `HEALTHCHECK_PORT` 打 `http://127.0.0.1:${HEALTHCHECK_PORT}/ready`，腳本不寫死埠號；需使用 `scripts/docker-build-images.sh` 建置的映像。

## 主要參數
- `-ComposeFile`
- `-EnvFile`
- `-Services`（預設 central、world、gate、chat、lobby、record）
- `-CheckMonitoring`：每步後再跑 production smoke
- `-ConfirmDrill`：非 `-DryRun` 時必須加，否則拒絕執行（預設 compose／env 是正式環境）
- `-DryRun`
