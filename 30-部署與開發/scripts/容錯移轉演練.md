# `scripts/failover-drill.ps1`

## 作用
逐個重啟 `central -> world -> gate`，驗證 failover。

## 目的
確認單一服務重啟後，整體鏈路仍能恢復。

## 流程
1. 檢查 compose 與 env。
2. 依序 stop / up 每個服務。
3. 每步都等 `ready` endpoint。
4. 可選擇再跑 production smoke。

## 主要參數
- `-ComposeFile`
- `-EnvFile`
- `-Services`
- `-CheckMonitoring`
- `-DryRun`
