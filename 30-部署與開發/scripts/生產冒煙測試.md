# `scripts/production-smoke.ps1`

## 作用
驗證 production 部署後的快速健康。

## 目的
確認核心服務 ready，必要時再連帶檢查 monitoring。

## 流程
1. 檢查 compose 與 env 檔。
2. 檢查 `mysql / redis / rabbitmq` 與六個自建服務（`central / gate / world / lobby / record / chat`）是否在 compose 裡。
3. 等 `ready` endpoint：在容器內以映像的 `HEALTHCHECK_PORT` 打 `/ready`，腳本不寫死埠號；需使用 `scripts/docker-build-images.sh` 建置的映像。
4. 若有 `-CheckMonitoring`，再檢查 Prometheus / Grafana。

## 主要參數
- `-ComposeFile`
- `-EnvFile`
- `-CheckMonitoring`
- Grafana 密碼不接命令列參數：先讀環境變數 `GRAFANA_ADMIN_PASSWORD`，沒有再讀 env 檔
