# `scripts/integration-deps-up.sh`

## 作用
啟動整合測試專用的拋棄式依賴：Redis、World MySQL、Central MySQL、RabbitMQ，容器名稱為 `pja-it-*`。

## 目的
整合測試使用固定的玩家與帳號 ID，並會寫入 Redis 與資料庫；預設連線的是本機開發環境（`docker-deps-up`）的連接埠，測試殘留會留在開發資料裡。專用依賴的埠號與開發環境錯開，用完可整組移除。

## 流程
1. 執行腳本，它會建立容器、等待 MySQL 就緒，最後印出需要的環境變數。
2. 在要跑測試的 shell 設定這些環境變數，再執行 `go test -tags integration ./integration/...`。
3. 用完執行 `./scripts/integration-deps-up.sh down` 移除容器。

## 主要參數
- `down`：移除 `pja-it-*` 容器
- 環境變數：`IT_REDIS_PORT`（26379）、`IT_WORLD_MYSQL_PORT`（23306）、`IT_CENTRAL_MYSQL_PORT`（23307）、`IT_RABBITMQ_PORT`（45672）

## 注意
- MySQL 維持預設的 UTC，印出的 DSN 不指定 `loc`（預設 UTC），與 CI 一致。若 DSN 加 `loc=Local`，測試裡 UTC 與本機時區的時間比較會失敗。
- 腳本每次執行都會先移除同名容器，資料不保留。
