# `scripts/session-gate.ps1`

## 作用
跑 session / duplicate login / duplicate logout 的 integration gate。

## 目的
確認 session 行為是 idempotent，而且舊連線會被正確踢下線。

## 流程
1. 執行指定的 integration test。
2. 驗證 duplicate login 與 duplicate logout 的語意。
3. 以 `go test -v` 執行，頂層通過的測試數必須剛好是 3；測試改名或刪除導致 0 個測試時以失敗結束，不會空跑綠燈。

## 主要參數
- `-DryRun`
