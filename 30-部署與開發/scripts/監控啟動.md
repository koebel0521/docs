# `scripts/monitoring-up.sh`

## 作用
一鍵拉起本機 monitoring stack，再接一次 smoke check。

## 目的
讓開發或值班快速得到可用的 Grafana / Prometheus。

## 流程
1. 找出專案根目錄與 `monitoring/compose.yml`。
2. 檢查 Docker 是否存在。
3. 用 `docker compose up -d` 啟動 Prometheus、Alertmanager、Grafana。
4. 若有 `powershell.exe`，再跑 `scripts/monitoring-smoke.ps1`。

## 主要參數
- 無。
