| 項目 | 理由 |
|------|------|
| s2sauth watcher 加 recover | 引入 recover helper 會造成 import 循環，維持現狀。 |
| GoPersist 改 TaskGroup | 已是 TaskGroup 管理，無需再改。 |
| board_router 內嵌欄位名 | 內嵌名稱有實際用途，非多餘命名。 |

| request_journal 與 memory_tx／player_snapshot 重複抽取 | 語意與生命週期不同，強行合併會耦合。 |
| World login／logout 的 Context() | RequestContext 仍在使用，非死碼。 |
| Lobby 封禁日誌保留帳號 | 維運稽核需要，刻意保留。 |
| resolve_shop 等級檢查 | 已有等級檢查，審查為誤報。 |
| 主倉庫 README.md | 被 `.gitignore` 忽略，不提交（本機已修改）；禁止 `git add -f`。 |
| topologybaseline／variablemigrate 註解 | 已符合規範，不需修改。 |
| GO-2026-5932 | 上游尚無修補版本，待釋出後升級。 |

## 行為變更

- 新帳號必須帶非空密碼，不再建立無 hash 帳號。
- 遊戲 trace 每個服務建立明確 root span，不再偽造遠端 parent。
- variablemigrate 傳入 `-dsn ""` 直接報錯。
- CI bench job 逾時放寬為 60m（`pkg/msg` 單包約 12 分鐘）。
- 告警規則的 `runbook_url` 使用 repo 相對路徑。
