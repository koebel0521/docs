## 行為變更

- 啟動：Gate `drain_timeout` 寫錯、環境變數與設定區段同名（`DEBUG`、`REDIS`、`GO`、`SESSION`、`MISSION_RESET` 等非空）、`go.memory_limit_mb`／`otel.sample_rate`／`redis.db` 寫錯、碉堡血量不能被 float32 精確表示、`-protocol-record` 寫錯，都拒絕啟動（旗標錯誤結束碼 2）。
- 熱重載：日誌改為 `config hot reload applied`（帶 `keys`）加 `config change requires restart, not applied`；可熱更白名單為 `protocol_record*`、`traffic_slice_*`、`admin_token`／`ops_token`／`gm_token`（token 只有 Lobby 真的重載）。
- RabbitMQ：broker 斷線時 outbox relay 整輪略過、不領取不計次；World 啟動連不上 RabbitMQ 以 Error 記錄（仍不重試）；Record 批次成功改批尾 `Ack(multiple)`。
- Central：登出與拒絕還原的共享路由寫入改背景執行（`GoBackground`），同一 Gate 的登出與重登若在背景任務亂序，共享路由可能短暫缺一筆；批次 journal 新增 `StoreManyDeferred`。
- Lobby admin：失敗鎖定期間直接拒絕、不比對 token，被鎖 IP 連正確 token 也回 429（同 NAT 取捨，約每 12 秒回復一次機會）。
- 資料庫：正式連線 `interpolateParams=true`、不使用 GORM `PrepareStmt`；寫 JSON 欄位禁用裸 `[]byte`；gorm 模型每欄明寫 `column:`；`VerifyDatabaseSchema` 10 秒逾時。
- HTTP：`MaxHeaderBytes=16KB`，存取日誌 path 截斷 256 bytes；OTLP 只在設定檔與 `OTEL_EXPORTER_OTLP_*ENDPOINT` 都未指定時才用明文。
- 指標與告警：新增 `recordmq_enabled`、`game_account_purge_total{result}`、`tcp_rejected_connections_total{reason="handshake_timeout"}`、`GameAccountPurgeFailing`；`GameRecordMQDisconnected` 不再用 6 小時 `max_over_time`；`GameMemoryPressureHigh` 改 `heap_inuse / go_gc_gomemlimit_bytes > 0.85`；`GameQueueOverflow` 事件佇列溢位現在會觸發；`game_board_command_total` 的 error 含內部失敗；玩家連線 handler panic 計入 `GamePanicRecovered`；`board command failed` 日誌每 10 秒取樣。
- 部署：World 關機最壞約 60 秒，prod 與 full compose 的 `stop_grace_period` 都改 70 秒；停機前預熱 Go 工具，被取消時自動回滾；外部 `REGISTRY` 要設 `REGISTRY_USER`／`REGISTRY_PASSWORD`。
- Gate 登入限流器上限 100,000 條目，滿載拒絕新 key。
- API 改名（tools/private 若有引用需同步）：`BuildingEffects`／`BuildingUpgrades`／`Levels` → `Buildings`、`LoadBuildingLevelsFromTables` → `LoadBuildingCatalogFromTables`、`RoadStarGroup(s)` → `DistrictLottery(ies)`、`RewardLotteryID`／`RewardChoicesLotteryID` → `RewardLotteryGroupID`／`RewardChoiceLotteryGroupID`、`DrawN` 參數 `times` → `multiplier`、`Client.DialAll()` → `IsDialAll()`、`tcpruntime.Superseded`／`faultinject.Enabled`／`mission.TimedOut`／`mission.ClaimExpired`／`effect.ExpiredAt`／`configcompat.MissionStateCompatible`／wallet `SameRequest` 加 `Is` 前綴、`LocalValidateRequestResult` → `...At`、`DefenderDebitGold` → `DefenderDebitedGold`（gorm column 不變）、`shop.Store.Purchase` 回傳 `PurchaseResult{Purchased, Balance, ItemQuantity}`、`lobbyreporter.New(rdb, keyPrefix, id, opts...)`。

## 待確認

### 需要負責人決策

1. **World 預設 READ COMMITTED**（database C2）：每筆 RC 交易多一次 `SET TRANSACTION` 往返；改在 DSN 指定會讓 World 其他交易一起變 RC。另外，outbox 單句批次 `UPDATE` 包在 RC 交易裡，是為了避開 REPEATABLE READ 的 gap lock 死結，改動前要保留這個理由。
2. **Central 一致性雜湊環**（popular-libraries C2）：FNV-1a 在 3 個節點時最重的一台分到 45～56%；改 xxhash 會讓帳號重新分配到不同 Central，上線時機要決策。
3. **`board.RollResult.StartSpaceID` 改名**（naming C1）：欄位存的是本次移動的出發格，與名詞定義的 Start（起點，即指揮中心）衝突；協定欄位來自 PJA-Protocol，要先改該專案。
4. **斷言訊息語言**（testing）：規則寫「assert 說明用英文」，新增測試大量用中文；先定規則再改。
