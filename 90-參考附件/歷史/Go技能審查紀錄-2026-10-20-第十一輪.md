## 行為變更摘要（文件已同步）

- 可觀測：`game_event_queue_overflow_total` 加 `action`（`closed`／`backpressure`），`GameQueueOverflow` 只看 `closed`，新增 warning `GameEventQueueBackpressure`；新指標 `game_ready_check_failing{check}`、`game_build_info{release, server_commit, config_version}`；新告警 `GameReadyCheckFailing`、`GameS2SHeartbeatTimeout`；`GameProcessRestarted` 排除發版重啟；`GameHeartbeatTimeoutSurge` 只看玩家且依在線數比例；重連錄製規則與兩條重連告警改依 `job`、`instance`、`service`；Chat 關機排空不計 `game_msg_queue_dropped_total`。
- Lobby 公告：Gate、Central、World 公告前跑 `CheckReady`，不就緒（含 redis、mysql 短暫失敗）時撤除公告。
- 關機：Gate `drain_timeout` 上限 40 秒（`MaxDrainTimeout`），超過拒絕啟動；debug／tracing 收尾各 2 秒、合計 4 秒計入契約，debug server 逾時強制 `Close`；`httpx.ServeLimited` 並行關閉多個 server；Lobby 寫入型 admin 請求不隨用戶端斷線取消；Record 自檢失敗以期限等背景工作；Lobby 遊戲時鐘迴圈 panic 後以錯誤結束。
- 安全：`-local-stack-only` 開發 token 綁非 loopback 位址時 Lobby、Record 拒絕啟動，Docker 開發堆疊以 `ALLOW_DEV_TOKENS` 放行；Chat 新設定 `room_max_members`（預設 500）。
- 資料庫：關閉 AutoMigrate 時比對索引，缺少記 Warn `AUTO_MIGRATE_DISABLED=true but indexes are missing; ...`，不擋啟動。
- 日誌：World `board command failed` → `board command failed (sampled)`（帶 `suppressed`），新增不取樣的 `board command failed: combat settlement incomplete`；關機遺失／落地日誌帶 `playerIDs`、`truncated`；gamestore 寫回 panic、World 個別請求背景工作 panic 帶 `playerID`；Record consumer panic 只記一次；Gate 登入登出與逐連線版本通知降為 Debug，另有彙總 Info；Gate 心跳逾時日誌鍵 `lastHeartbeat` → `lastActivity`。
- 計量分類：無效 `ChosenRewardID` 由 `error` 改 `ok`（Rejected）；任務存檔損毀、任務服務未設定、戰鬥場次資料損毀改計 `error`。
- 工具鏈：`go.mod` 加 `ignore ./tools/private`，根模組 `go mod tidy -diff` 改在本機、pre-commit 與 CI 都檢查；`make ci-unit`、`ci-it-pkg` 與 CI integration 帶同一 `-coverpkg`；`make ci-lint` 加 `scripts/ci-lint-extra.sh`；新增 `make hooks` 與 MR `perf-commit-msg` job；other GOOS hook 改以平台後綴觸發；`make outdated` 只列實際用到的 module；gomodguard 補擋 go-redis v8、redigo、streadway/amqp、golang-lru v1；releasemanifest 依 lock 重算 schema hash。
- 腳本：`world-autoscale.ps1` dry-run 也查容器；`upgrade-window.ps1` 壞鎖檔視為已上鎖；`change-approval.ps1` 的 `-ChangeType` 必填；`reconcile-test.ps1` 要求 17 個測試通過；`backup-restore-drill.sh` INT／TERM 回 130／143；`ci-deploy.sh` 回滾設定切回失敗回非 0、缺參數回 2；S2S 檢查腳本拒絕 `python -O`；`docker-deps-up.sh` 不必在倉庫根執行。
