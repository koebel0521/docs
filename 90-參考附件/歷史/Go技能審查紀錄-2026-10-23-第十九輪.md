## 中

- **DP-M1** `pkg/mysql/breaker.go:19`、`pkg/circuitbreaker/executor.go:50,72-80`：MySQL 斷路器把 callback panic 算成「成功」。gobreaker v2.4.0 `Execute` 在 panic 時先以 `fmt.Errorf("%v", e)` 呼叫 `afterRequest`（gobreaker.go:224-229）才 re-panic，`executeRecovering` 的 recover 在那之後，所以 `BreakerSettings.IsSuccessful = !IsInfraError(err)` 看到普通字串錯誤 → true → `onSuccess`。探針：4 次 `DeadlineExceeded` 後 `ConsecutiveFailures=4`，再一次 panic → `ConsecutiveFailures=0, TotalSuccesses=1, state=closed`。影響：DB 故障期間夾一次毒資料 panic 就歸零連續失敗延後熔斷；Half-Open 試探 panic 直接關回；`executor.go:50` 註解只對 `DefaultSettings` 成立。Redis `resilient_store.go:32` 不受影響。修法：recover 搬進傳給 `cb.Execute` 的閉包內回 `ErrCallbackPanic` 包裝錯誤，`BreakerSettings.IsSuccessful` 加 `&& !errors.Is(err, circuitbreaker.ErrCallbackPanic)`；補以 `mysql.BreakerSettings` 建 breaker 的 panic 測試。
- **B（DI-M1）** `cmd/world/internal/services/services.go:400,403`：`startWorldTransport` 以 setter 接 `memory.SetChangeNotifier(gateHandler.NotifyChange)` 與 `baseApp.SetPlayerForgetter(variables.ForgetPlayer)`，nil 都靜默略過；單元測試走不到 `startWorldTransport`，探針刪任一行全綠。影響：漏接 `:403` 時其他 World 的 PvP 扣款與 GM 發放不推給在線玩家（舊值直到重登）；漏接 `:400` 變數遷移快取不清。修法：比照 `lateClock` 建 `late` 綁定（bind 前呼叫 panic），`NewMemory` Option 必填；`SetPlayerForgetter` 改必填；刪兩 setter；DI-L4 `WithResourceReader` 同處一併必填。
- **B（DI-M2）** `cmd/gate/internal/services/userserver.go:52-58,86-100`＋`flow/user/login/coordinator.go:42,80-82`：封禁檢查是可選 Option，`banChecker == nil` 直接轉 Central；`startUserServer` 只在 `rc != nil` 接上。探針把兩個 `if rc != nil` 改恆假（封禁＋GM 踢人佇列都不接）後 `cmd/gate/internal/services` 全綠。SC 補充：`cmd/gate/run.go:71-79` 正式路徑 Redis 必建，nil 只在測試出現，是接線風險非現行漏洞。修法：`rc` 改必填刪 nil 分支（或 panic）；`login.New` `banChecker` nil 回錯；補接線測試（`user.Handler` 加 `BanChecker()` getter）。
- **C（CLI-M1）** `scripts/migrate-prod.sh:9`：`exec "${DATABASE_ROOT}/scripts/migrate-prod.sh"` 不轉送 `"$@"`，參數靜默丟棄，內層固定 `-mode apply -confirm`。探針 stub：`./scripts/migrate-prod.sh -mode validate -dry-run` → `inner got 0 args`、rc=0。維運帶 `-mode validate` 預檢實際直接 apply。修法：開頭 `[[ $# -eq 0 ]] || { echo "usage: $0  (no arguments; set MYSQL_DSN, MIGRATION_* in env)" >&2; exit 2; }`。
