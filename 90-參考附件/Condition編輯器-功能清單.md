# Condition 編輯器：功能清單與進度

編輯 `PJA-Config/Datas/Condition.xlsx` 條件運算樹的工具，程式在 `PJA-Tools/ConditionEditor/`。本文件列出所有提過的項目：已完成、做過後移除、尚未做、以及已知限制。使用方式見 `ConditionEditor/README.md`。

更新日期：2026-10-06。「提交」欄是 `ConditionEditor` 這個本機 git 專案的提交編號（沒有推送到遠端）。

## 1. 已完成

### 1.1 基本能力

| 項目 | 說明 | 提交 |

## 4. 已知限制與未驗證

- **拖放、鍵盤、框選、雙欄、新手導覽**：開發時用程式模擬事件測過，沒有真人實際操作過；導覽的聚光燈暗化在開發用的瀏覽器窗格沒有看到效果，樣式查驗正確，請實際看一次。
- **`啟動.cmd` 自動安裝 `openpyxl`** 的流程只驗證了語法與「缺 Python」的分支，沒有真的跑過安裝。
- **exe** 只在開發電腦驗證，沒有在沒裝 Python 的乾淨電腦上跑過。
- **試算情境**屬於單一條件，不能跨條件共用（跨條件請用頂端「情境矩陣」，依情境名稱合併）。
- **恆真／恆假檢查**：格子次數視為 ≥ 0；建築等級只知道上限；兩個變數互相比較、或兩邊都是複雜式子的比較只能保守判斷。
- **反推最小解**是啟發式搜尋，建築等級以 0 為下限；搜尋步數有上限，找不到不代表一定矛盾。
- **Excel 列號**是載入檔案時的位置，改動後會變。
- **雙欄的連線圖**兩欄共用同一個平移縮放狀態；非作用欄的連線圖只畫、不互動。
- **自訂的 Excel 格式**：寫入時所有資料列統一套第一個有框線的資料列格式，原本刻意不同的列格式會被統一。
- **Luban 對引用不檢查**（見 3.2）；Type 4 的存在與循環由編輯器與 Server 載入時把關。
